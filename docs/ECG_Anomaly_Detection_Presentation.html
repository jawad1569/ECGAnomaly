Problem

Abnormal ECGs wait in the same queue as normal ones

  • The ECG is the most common first test for heart disease.
  • Reading it needs trained staff, so recordings queue up.
  • An automatic normal / abnormal flag helps decide what a doctor reviews first.

The MLOps problem

A model in a notebook helps no one. It must be reproducible, served, packaged, deployed and monitored, and easy to update or roll back.

Dataset

PTB-XL Reformatted: real clinical ECGs with expert labels

~21,800
ECG recordings in PTB-XL, de-identified and public
12 leads
10 seconds each, about 1,000 samples per lead at 100 Hz
5 classes
labelled by cardiologists, grouped into normal vs abnormal
  • Two files: train_signal.csv (one row per time step) and train_meta.csv (labels), joined on ecg_id.
  • Target: 0 = normal (NORM), 1 = abnormal (MI, STTC, CD or HYP).
  • Only a small sample is committed; the full data is downloaded by make data.
Source: PTB-XL, PhysioNet (Wagner et al., 2020)
MI = myocardial infarction, STTC = ST/T change, CD = conduction disturbance, HYP = hypertrophy. We collapse them into one "abnormal" class to keep the task simple.
Model & evaluation

Simple features, three model families, one metric

Pipeline

  • Validate: missing values, 12 leads, length, amplitude range.
  • Features: 9 statistics per lead = 108 features.
  • Split: fixed, stratified 80/20 train/test.
  • Models: logistic regression, random forest, gradient boosting (scikit-learn).

Metric: F1 of the abnormal class

Balances missed abnormal ECGs against false alarms. Accuracy alone would hide errors when classes are unequal.

MLflow

Every run logs parameters, F1 and the model. At least 3 runs; the best one is justified in the README.

ECG Anomaly Detection
Tuning uses 5-fold cross-validation on the training set only; the test set is scored once.

Deployment & updates

Deploy with one command, update safely, roll back fast

Package

Dockerfile with the model, code and a healthcheck on /health. Runs with one documented command.

Automate

GitHub Actions: ruff lint, pytest, Docker build on every push. Images tagged by commit and pushed to GHCR.

Deploy

One AWS EC2 instance runs the container behind a public URL.

Only if better

Models saved as ecg_model_vN. A retrained model replaces the live one only if its F1 is at least as good.

Roll back

Run the previous image tag. Steps written and rehearsed in RUNBOOK.md.

Monitor

Request count and average latency from /metrics and structured logs.
